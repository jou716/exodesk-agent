# U1 数据层验收

状态：**已人工验收**（2026-10-31）。U2 已开始。

## 本单元范围

- MySQL 数据模型：工单、消息、设备、文档源、文档分片、Agent 运行、步骤、草稿、反馈、Webhook 事件。
- 合成演示数据：12 个工单、7 台设备、4 份英文模拟手册、26 个可检索分片。
- 文档索引：MySQL 存原文与业务标签，Chroma 存向量；Chroma 异常时保留 MySQL 关键词降级。
- 初始化与重置脚本：可重复执行，不依赖真实厂商资料。

## 数据分布

| 类型 | 数量 | 说明 |
|---|---:|---|
| 工单 | 12 | 普通咨询、故障、高危、资料不足、已关闭 |
| 消息 | 13 | 中英文客户消息，含一条坐席回复 |
| 设备 | 7 | K2 / H1 / A3 三个虚构型号 |
| 文档 | 4 | 3 份型号手册 + 1 份安全指南 |
| 文档分片 | 26 | 带型号、页码、章节、关键词 |

## 重点样例

- `T-2401`：K2 固件更新，普通咨询。
- `T-2402`：K2 膝关节异响 + E-12，中文故障。
- `T-2403`：客户摔倒 + 膝关节锁死，高危硬拦截。
- `T-2406`：A3 突然断电 + 踝关节锁死 + 烧焦气味，高危硬拦截。
- `T-2408`：K2 充电口发烫，中风险/安全提醒。
- `T-2411`：没有序列号，用于验证“证据不足不编造”。
- `T-2410`：已关闭工单，用于验证会话结束行为。
- `K2-2024-00119`：召回状态，用于设备档案和召回提示。

## 运行与检查

在 `D:\工单agent项目\backend` 下执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\init_demo.ps1
```

预期输出：

```text
tickets 12
messages 13
devices 7
docs 4
chunks 26
```

也可以直接查询 MySQL：

```sql
SELECT id, subject, serial_no, risk_flag, status FROM tickets ORDER BY id;
SELECT serial_no, model, recalled, warranty_status FROM device_profiles ORDER BY serial_no;
```
